models/ — Model fayllari

Mavjud fayl:

- yolov8n.pt — YOLOv8 (nano) model fayli. Ushbu fayl ultralytics kutubxonasi yordamida yuklanadi va real-time deteksiyada ishlatiladi.

Tavsiyalar:
- Agar aniqlik kerak bo‘lsa, `yolov8s.pt` yoki `yolov8m.pt` kabi kattaroq modellarni ishlatish mumkin (tezlik/aniqlik o‘rtasida kompromis).
- Model faylini yangilaganda yoki o‘zgartirganda `src` ichidagi skriptlarda `model_path` ni mos ravishda sozlashni unutmang.
- Model fayli kattaligi sababli versiya nazorati (git) ga kiritmaslik, uning o‘rniga `models/README.md` ga model manzilini va talablarni yozishni tavsiya etamiz.
